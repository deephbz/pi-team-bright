Date: 2026-08-05

## Requested correction

The owner requested a higher release after rc.7. `leader_share` now accepts
values strictly greater than `0.1` and strictly less than `1.0`; its default
remains `0.6`. The README contains one combined Team and Worker settings example
and states Worker tool-list precedence.

Worker tool projection remains additive and subtractive. It starts with the
inherited Worker active list, adds known registered names from `enable`, then
removes known registered names from `disable`. Thus `[A, B, C]` with `enable:
[E]` and `disable: [C]` becomes `[A, B, E]`. Disable wins when both lists contain
the same name. Unknown names produce a diagnostic, and settings cannot restore
leader-only tools or grant authorization.
