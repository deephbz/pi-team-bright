# Current context

This directory is the maintained, intentionally concise view of what matters to
pi-teams now. Update it when source, tests, or an accepted decision change; do
not use it as a chronological log.

- [Product and scope](product.md) defines the supported collaboration boundary.
- [Domain](domain.md) defines the terms that the public contract relies on.
- [System](system.md) records authority boundaries, lifecycle, delivery, and
  integration limits.
- [Operations](operations.md) is the maintained operator workflow.

The exact tool and parameter contract is [the reference](../reference.md).
Accepted choices live in [decisions](../decisions/), and dated observations and
changes live in [the journal](../journal/).
