# Pi Team Bright v0.18.0

Assign each Worker a short model-profile alias. Keep a frontier reviewer beside
cost-efficient scouts and test Workers without repeating provider/model IDs in
Task graphs.

## Worker model profiles

- Configure aliases under `pi_team_bright.model_profiles` in Pi settings.
  Each profile selects a provider, model ID, thinking level, and short usage description.
- Select an alias with `ensure_worker({ name, scope, model })` at Worker creation.
  Reuse retains that binding; conflicting selections refuse.
- Team creation and snapshots expose a compact alias catalog. Invalid selections
  return valid choices before Worker creation.
- Successful and failed Worker TUI results show settings guidance. Ctrl+O exposes
  a copyable example.
- Human model/thinking changes in Pi remain authoritative. Recovery into the same
  Session preserves them. Pi Team Bright does not switch models between Tasks.

Start with the [settings example](https://github.com/deephbz/pi-team-bright/blob/v0.18.0/docs/examples/worker-model-profiles.settings.json).
Replace its model IDs with exact available models from `pi --list-models`.

## Breaking upgrade boundary

This release removes the old per-Task `model: "default" | "capable"` mechanism.
Tasks select an assignee only. Old graph snapshots with Task/Attempt model fields
are refused. There is no backward-compatibility or migration path.

Finish or stop existing Teams under their original version before upgrading.
Preserve their stores and native Session logs. Start new Teams under `0.18.0`;
do not reload this release into an existing live Team. Update saved Task graphs
and prompts to select model aliases only at Worker creation.

```sh
pi install npm:@hypercarrier/pi-team-bright@0.18.0
```

Restart Pi after installation. Profile omission retains the existing Worker
model-default behavior. Profiles do not change the leader model or grant tools,
prompts, roles, or permissions.

Pi `>=0.83.0` remains required. The read-only Membership observation protocol
remains `pi-teams-observation/1`.
