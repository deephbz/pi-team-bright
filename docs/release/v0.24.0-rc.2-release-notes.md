# Pi Team Bright 0.24.0-rc.2

This is a prerelease on npm `next`. It fixes three defects that live tests of
0.24.0-rc.1 found, and adds proposed Decision 0022. Install it by exact
version:

```sh
pi install npm:@hypercarrier/pi-team-bright@0.24.0-rc.2
```

For a live Team, reload the lead's Pi first, then reload each Worker's Pi.

## Finished turns read as idle

Herdr reports a finished Worker turn as `done`. PTB now maps `done` to activity
`idle`. Before, each finished turn journaled activity `unknown`, and idle Workers
showed "activity unknown" in `team_sync` and `/ptb status`. An unrecognized
Herdr status stays `unknown`, and the evidence keeps the raw value.

## Attention for a legacy Worker without a birth token

A bound Worker that was admitted before 0.24.0 has no birth token. PTB now
reports `legacy_unverified` with `ask_human` for it in `team_sync` snapshots,
update pages and `/ptb status`. The evidence names the PID and the helper's
result for it (absent, present or unknown), and the text gives the human's next
action. Before, the snapshot showed such a Worker as connected with no
attention, even when its Pi was gone. This attention never starts, replaces or
marks a Worker gone.

## Recovery when every Worker pane has closed

Herdr writes its error reply to stderr and leaves stdout empty. PTB read only
stdout, so a closed pane gave "Herdr returned malformed JSON." When every
registered Worker pane had closed, `ensure_worker` recovery could not place a
new pane, and the launch became unknown. PTB now reads Herdr's error reply from
stderr for every call. Placement uses only Worker panes that still exist. With
none left, the new pane splits from the lead's pane, as for a first Worker.

## Decision 0022 (proposed)

Decision 0022 records that the terminal multiplexer and the agent harness are
replaceable. Adapters own all external formats and status names. The owner has
not ratified it yet.

## Not in this release

- The `team_sync` quiet-result change stays deferred.
- Worker progress recording depends on Worker instructions. Nothing enforces it.
