# Pi Team Bright v0.17.3

Status: stable patch candidate. This document becomes the GitHub Release body
after source, hosted, registry, and provenance gates pass.

## Name Herdr Worker panes from the exact split result

Pi Team Bright now uses Herdr's official pane-label command immediately after a
Worker split:

```text
herdr pane rename <exact split pane> <stable Worker name>
```

The adapter uses only the pane handle returned by `herdr pane split`. It does
not infer the target from focus, tab position, title, or recognized Agent name.
The label is applied before the existing official `agent start` readiness call,
so it does not mutate display state inside that readiness window.

Pane labels are presentation. A rename failure records a payload-free launch
stage and warning, then continues Worker startup. It cannot prevent Team
coordination or change Membership, Session, Agent, Task, or Worker identity.

A real Herdr 0.7.5 probe applied the extra local command in 24.72 ms. The
separate six-second interactive-readiness bound and exact Session-binding
observation remain unchanged.

## Compatibility

Version `0.17.3` is backward compatible with `0.17.2`, `0.17.1`, and `0.17.0`
Team state. It does not change Team storage, Task graph, model-tool, Membership,
or Worker protocol contracts. Do not recreate a Team for this update. Restart
Pi processes that must load the new adapter.

## Install

Install the exact version and restart the Pi processes that must load it:

```sh
pi install npm:@hypercarrier/pi-team-bright@0.17.3
```
