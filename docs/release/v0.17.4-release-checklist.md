## Compatibility and boundaries

Version `0.17.4` is backward compatible with `0.17.3`, `0.17.2`, `0.17.1`, and
`0.17.0` Team state. It changes no Team storage schema, Task graph, model-tool,
or Worker protocol contract.

- Direct and Task delivery are one exact recipient Session actuator pair.
- Initial create, fork create, lead resume, and Worker binding activate the pair.
- Admission refusal, Session shutdown, and successful full Team shutdown stop it.
- Partial Team shutdown retains the current leader binding and pair.
- Full shutdown deletes only the exact lead runtime generation and fails closed
  around malformed, foreign, or changed evidence.
- A stopped direct-delivery generation cannot arm, send, acknowledge, or block a
  later generation.
- Do not copy private machine paths or live Team payloads into tracked content.
- Use the nonce-v1 GitHub Actions OIDC workflow for `latest` publication.
