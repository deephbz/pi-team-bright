# Pi Team Bright 0.23.0

## Task goals

Task goals now default to a maximum of 1600 TypeBox string-length units.
Set `pi_team_bright.task.goal_max_length` in global Pi settings to change the
limit. Restart all Team Pi processes after changing it.

## Delivery holds

PTB honors token-owned external `hc.delivery-hold` windows, including Auto
Compact handoff. Native compaction and external holds remain independent.
Repeated begin signals renew a 30-minute lease. Expiry warns and releases only
that token. Session reset clears holds and old-target sends.

## Worker startup

Worker admission preserves contention recovery without a persistence-lock wait
budget. Uncertain launch probes keep observing carrier liveness and exact
failed events. Exact launcher refusals identify their Membership and cannot
fail a replacement. Herdr readiness and binding observation use a five-minute
hang ceiling.

## Compact identity and HUD

New Teams receive a local `YYYYMMDD-` prefix by default. Set
`pi_team_bright.team.date_prefix` to `false` to disable it. Existing Team names
and logical Worker identities remain unchanged.

Leader panes and terminal titles use `leader-<team>`. Worker panes use
`<worker>`. PTB enforces Worker Session names as `<team>/<worker>` and leaves
leader Session names to `/name` or Rarebit. Rarebit normally skips auto-title
because PTB names the Worker at startup; a failed startup naming call can
leave a temporary unnamed interval.

PTB publishes a semantic `team.member` slot for an optional HUD composer.
Without a composer, its footer wrapper shows only the role. The last-message
clock no longer occupies the footer. No sidecar or new persistence store is
introduced.

## Upgrade

Finish or stop active Teams on their original version. Preserve Team stores and
native Session logs, update the package, then restart Pi. Start new Team epochs
on the new version. Publication does not change personal Pi settings or enable
an optional HUD composer.
