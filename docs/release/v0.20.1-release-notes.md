# Pi Team Bright v0.20.1

This patch adds the product demo to the README and release notes. It also
updates the packaged lead guidance to start independent and reversible work
early while preserving dependencies and approval boundaries.

The README thumbnail links to the full video. The reproducible source bundle
lives in [`brand/promo-video/`](https://github.com/deephbz/pi-team-bright/tree/v0.20.1/brand/promo-video).
It shares the product's brand primitives and includes the timeline, reading
budget check, deterministic soundtrack generator, and review history.

## Early starts

The lead guidance now asks agents to start independent Tasks together and
split useful reversible work from dependent verification. Early Task success
proves only that Task's bounded outcome. Integration checks and irreversible
effects still wait for their actual dependencies and approvals.

Install with `pi install npm:@hypercarrier/pi-team-bright@0.20.1`, then restart
Pi. Team storage, model tools, and the Worker protocol are unchanged from
`0.20.0`. No Team migration is required. Pi `>=0.83.0` remains required.
