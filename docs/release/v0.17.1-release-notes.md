# Pi Team Bright v0.17.1

Status: published stable patch on npm `latest` with SLSA provenance and a
[stable GitHub Release](https://github.com/deephbz/pi-team-bright/releases/tag/v0.17.1).
The exact evidence is in the
[release receipt](../journal/2026-08-16-v0.17.1-release-receipt.md).

## Fix the graph pane after its origin moves

In Herdr, `/pi-team-graph` now resolves its origin tab and workspace from the
exact live origin pane. A pane move can leave inherited tab and workspace values
stale while the exact pane ID remains valid. The graph pane now opens beside that
live origin and keeps the resolved location for child placement and close
fencing.

The pane still refuses a missing or non-exact origin. It still refuses a child
outside the live origin location. It never changes Tasks or schedules work.

## Retry a departed recovery claim

A contender that loses stale-lock recovery claim creation now retries if the
winning claim disappears before inspection. A present stale malformed claim
still fails closed. This change does not alter normal lock ownership or release
semantics.

## Compatibility

Version `0.17.1` is backward compatible with `0.17.0` Team state. It only
resolves the live Herdr graph-pane origin. It does not change Team storage, Task
graph, model-tool, or Worker protocol contracts. Do not recreate a Team for this
update.

## Install

Install the exact version and restart the Pi processes that must load it:

```sh
pi install npm:@hypercarrier/pi-team-bright@0.17.1
```
