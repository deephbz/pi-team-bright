# Pi Team Bright v0.20.0

## Watch the demo

https://github.com/user-attachments/assets/cc4038d1-eede-4391-a7b2-34bdbb950d9b

This release adds one `/ptb` command palette, validated editing of scoped
settings, and one transcript presentation for PTB messages. It also introduces
the Pi Team Bright brand and website. It is backward compatible with `0.19.0`
Team state: Team storage, the Task graph, model tools, and the Worker protocol
do not change.

## One `/ptb` command

Run `/ptb` in interactive Pi to open the command palette. Tab and Shift+Tab
switch between Actions, Models, Team, and Workers. Actions include status, sync,
graph, doctor, settings diagnostics, and help. Direct subcommands use the same
handlers: `/ptb status`, `/ptb sync`, `/ptb graph`, `/ptb doctor`,
`/ptb settings`, and `/ptb help`. In RPC or headless mode, bare `/ptb` shows
help. The old `/pi-team-bright`, `/teamsync`, `/pi-team-graph`, and
`/pi-team-bright-settings` names remain aliases. See the
[command palette guide](https://github.com/deephbz/pi-team-bright/blob/v0.20.0/README.md#command-palette).

## Scoped settings editing

`/ptb settings [global|project]` edits the `pi_team_bright` namespace in Pi's
global `settings.json` or, with project trust, in `.pi/settings.json`. Every
edit requires Save confirmation. Invalid settings, or a file changed since it
was opened, refuse the save. Other Pi settings stay intact. Edits apply to new
Teams, new Workers, or new Worker processes; they do not change live Team
records.

## Transcript presentation

PTB tool results and custom messages share one presentation: a short `PTB ·`
header, an explicit status line, and a concise summary. Expanded mode shows
readable content first and diagnostic JSON after it. From a source checkout,
`npm run review:tui` and `npm run review:graph` render these displays with
fixed fixtures and no model, Team, or multiplexer. See the
[TUI review guide](https://github.com/deephbz/pi-team-bright/blob/v0.20.0/docs/maintainers/tui-review.md).

## Brand and website

The repository gains a single-source brand in `brand/`: tokens, copy, drawing
primitives, the mark, and the lockup. A build derives the logo, favicon set,
README banner, social preview, and the project website on GitHub Pages. The
brand is not part of the npm package. Dead root material from the original
fork and one-off benchmark harnesses were removed.

Install with `pi install npm:@hypercarrier/pi-team-bright@0.20.0`, then restart
Pi. Do not recreate a Team for this update. Pi `>=0.83.0` remains required. The
read-only Membership observation protocol remains `pi-teams-observation/1`.
