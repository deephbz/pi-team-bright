# Pi Team Bright v0.17.4

Status: stable patch candidate. This document becomes the GitHub Release body
after source, hosted, registry, and provenance gates pass.

## Deliver Worker Alerts to a newly created Team leader

Pi Team Bright now activates direct-Message and Task-change delivery as one
recipient pair when `team_create` binds the current leader Session. This fixes
Worker-to-leader Alerts that were accepted and persisted but not presented
until the leader Session later resumed or reloaded. Explicit Team creation from
a fork uses the same transition.

The pair has one internal lifecycle. Binding replacement stops the old pair
first. A start failure compensates both engines. Admission refusal, Session
shutdown, and successful full Team shutdown leave no active recipient pair.
Partial Team shutdown retains the current leader binding and pair.

Full Team shutdown now removes only the exact lead runtime generation before it
deactivates the Membership. It restores that generation if deactivation fails,
and it fails closed around malformed or foreign runtime evidence. The shutdown
Task snapshot completes before any carrier or Membership mutation.

Direct-Message delivery also generation-fences asynchronous start, scan, and
acknowledgement work. A stopped generation cannot later arm a watcher, send a
Message, block a restart, or clear a newer scan.

## Team operating policy

A Team normally aligns with a project or another durable coordination boundary.
Reuse it for related Tasks. Workers can be reusable standing capacity or
ephemeral bounded capacity. Do not create and shut down a Team for each Task.

## Compatibility

Version `0.17.4` is backward compatible with `0.17.3`, `0.17.2`, `0.17.1`, and
`0.17.0` Team state. It changes no Team storage schema, Task graph, model-tool,
or Worker protocol contract. Do not recreate a Team for this update. Restart Pi
processes that must load the new Session adapter.

## Install

Install the exact version and restart the Pi processes that must load it:

```sh
pi install npm:@hypercarrier/pi-team-bright@0.17.4
```
