# v0.20.0 release checklist

Status: in preparation.

Follow [Releasing](../maintainers/releasing.md). Record run IDs, package
integrity, registry state, and provenance in a dated release receipt after each
gate completes. Keep integration E2E evidence separate from release execution.

## Identity and boundary

- Package: `@hypercarrier/pi-team-bright@0.20.0`
- Annotated tag: `v0.20.0`
- npm dist-tag: `latest`
- [Release notes](v0.20.0-release-notes.md)
- Compatible minor: no Team storage, Task graph, model-tool, or Worker protocol
  change. Old slash commands remain aliases.
- No live Team migration, installed-settings change, or parent composition is
  part of npm publication.

## Reversible gates

- [ ] Confirm the exact release commit is merged to `main` and CI is green.
- [ ] Confirm version and tag are absent in npm and Git before publication.
- [ ] Confirm the working tree is clean at the exact release commit.
- [ ] Record an independent real Pi Team integration E2E result from a fresh
  Herdr tab and disposable Team. Keep its evidence distinct from publication.
- [ ] Run full tests, test-lane closure, generated/package verification, and
  `npm pack --dry-run --json` on the final source.
- [ ] Complete the public privacy scan and record the audited commit.
- [ ] Pack once from a clean detached checkout. Record the tarball SHA-512.
- [ ] Install that exact tarball in an isolated project and run the Pi canary.
- [ ] Dispatch **Publish npm package** with `dry_run: true`. Record its nonce,
  run, exact head SHA, and skipped publish step.

## Publication and receipts

- [ ] Create and push the annotated `v0.20.0` tag after reversible gates pass.
- [ ] Publish the tagged package through GitHub Actions OIDC with `latest`.
- [ ] Match registry bytes and integrity to the recorded tarball. Check the
  observed `latest` dist-tag, provenance, and signatures.
- [ ] Create and verify the matching stable GitHub Release.
- [ ] Keep downstream HyperCarrier composition separate; it was not changed.

Architecture impact: **none** at the HyperCarrier boundary. PTB adds an internal
configuration editor and a unified transcript renderer. The brand and website
live outside the npm package.
