# Pi Team Bright 0.25.1

This patch release fixes one install failure in 0.25.0 and the 0.24.0
prereleases. It has no runtime change.

## Fix

On macOS, installation failed when `rustc` was present but could not build
the process-generation helper, for example when the Xcode license was not
accepted. The `postinstall` hook now prints a warning with the last lines of
the compiler output and exits 0. Installation succeeds, and PTB warns at Pi
startup that the helper is missing, as it does when `rustc` is absent.

To build the helper later, make Xcode Command Line Tools work, then run
`npm run build:process-generation` in the installed
`@hypercarrier/pi-team-bright` directory.

## Upgrade

```sh
pi install npm:@hypercarrier/pi-team-bright@0.25.1
```

Reload the lead's Pi first, then each Worker's Pi. From 0.23.1, read the
[0.25.0 release notes](v0.25.0-release-notes.md) first.
