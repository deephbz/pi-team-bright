# Pi Team Bright 0.24.0-rc.7

This is a prerelease on npm `next`. It adds a read-only Task observation for
viewers. Teams, Tasks, Alerts and the on-disk formats do not change.

## Upgrade from 0.24.0-rc.6

1. Install the exact version. `/reload` alone keeps the pinned old version.

   ```sh
   pi install npm:@hypercarrier/pi-team-bright@0.24.0-rc.7
   ```

2. Reload the lead's Pi first, then reload each Worker's Pi.

No data migration is necessary.

## Task observation

`@hypercarrier/pi-team-bright/observation` now exports `readTaskSnapshot`. It
returns a `pi-team-tasks/1` snapshot of one Team's Task graph: each Task's
title, status, owner and dependencies, and whether it is on the ready frontier.

A viewer can show the Task graph without reading Pi Team Bright's storage
itself. The read is read-only: it takes no lease, creates no directory and
starts no delivery. A missing, corrupt or changing store reports
`availability: "unavailable"` with an issue code, never an empty Task set.
