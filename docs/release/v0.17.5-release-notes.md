# Pi Team Bright v0.17.5

Status: stable patch candidate. This document becomes the GitHub Release body
after source, hosted, registry, and provenance gates pass.

## Keep Team topology aligned with durable work

The packaged operating skill now separates the lifecycles of Team, Worker, and
Task. A Team follows one project or durable coordination boundary and remains
alive across related requests, terminal Task graphs, empty ready fronts, and
idle intervals. Only an explicit owner or operator decision ends or resets that
boundary.

Worker creation now has a positive test. Add a Worker when it unlocks parallel
independent work, establishes a distinct reusable semantic scope, or
deliberately isolates context or perspective. Otherwise reuse suitable current
capacity. Implementation, execution, diagnosis, and repair normally preserve
one Worker's causal context; independent review and alternative experiments can
use fresh Workers when independence itself is valuable.

This keeps Task granularity separate from Team topology. A new Task no longer
implies a new Worker, and completed Tasks do not imply Team shutdown.

## Compatibility

Version `0.17.5` changes packaged agent operating guidance only. It changes no
Team storage schema, Task graph, model-tool, Membership, runtime, terminal, or
Worker protocol contract. Existing Teams remain compatible and should not be
recreated for this update.

## Install

Install the exact version and restart the Pi processes that must load the
updated packaged skill:

```sh
pi install npm:@hypercarrier/pi-team-bright@0.17.5
```
