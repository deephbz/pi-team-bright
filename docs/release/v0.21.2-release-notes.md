# Pi Team Bright v0.21.2

## No delivery during compaction

Pi Team Bright no longer sends model messages while Pi compacts a Session.
Previously, a Task change, an Alert, an automatic team_sync, or `/ptb doctor`
could arrive during compaction. During manual compaction, such a message
started a new agent run beside the summary request.

Pi Team Bright now holds these messages until compaction ends. It then sends
them in their original order. Automatic team_sync waits for compaction to end.
If Pi 0.83 cannot report a failed or cancelled compaction, held messages are
released after 15 minutes.

## Upgrade

Install `pi install npm:@hypercarrier/pi-team-bright@0.21.2`, then restart Pi.
No Team storage migration is required. Pi `>=0.83.0` remains required. Tools,
settings, and the public Membership observation protocol are unchanged.
