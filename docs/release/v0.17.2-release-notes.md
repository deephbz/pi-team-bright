# Pi Team Bright v0.17.2

Status: stable patch candidate. This document becomes the GitHub Release body
after source, hosted, registry, and provenance gates pass.

## Use Herdr's official Worker start command

Pi Team Bright now starts Herdr Workers through one released CLI contract:

```text
herdr agent start <carrier> --kind pi --pane <pane> --timeout 6000 -- <pi arguments>
```

The adapter no longer attempts the unreleased `--wait accepted` prototype. It
no longer detects its parser rejection, retries a second command, or caches a
process-local capability result.

The explicit timeout bounds Herdr interactive readiness at six seconds instead
of its 30-second default. Successful starts return when readiness appears; they
do not wait for the full timeout. Exact Membership and Session binding remains
a separate authority check with its ordinary observation policy.

Released Herdr 0.7.5 and 0.8.0 support this command. Both versions already used
the old fallback path, so this patch does not add a readiness wait to supported
installations.

## Compatibility

Version `0.17.2` is backward compatible with `0.17.1` and `0.17.0` Team state.
It does not change Team storage, Task graph, model-tool, or Worker protocol
contracts. Do not recreate a Team for this update.

Concurrent sibling `ensure_worker` launch remains deferred design work. This
patch does not change Pi's sequential execution policy for that tool.

## Install

Install the exact version and restart the Pi processes that must load it:

```sh
pi install npm:@hypercarrier/pi-team-bright@0.17.2
```

[`v0.17.2-release-checklist.md`](v0.17.2-release-checklist.md).
