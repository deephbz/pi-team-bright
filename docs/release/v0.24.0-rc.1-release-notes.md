# Pi Team Bright 0.24.0-rc.1

This is a prerelease on npm `next`. It changes how PTB records what the lead has
seen and how it decides whether a Worker's Pi is alive. Install it by exact
version:

```sh
pi install npm:@hypercarrier/pi-team-bright@0.24.0-rc.1
```

For a live Team, reload the lead's Pi first, then reload each Worker's Pi. See
"Carrier-liveness upgrade" in the README.

## Team cursor on the lead's branch

- The lead's Session branch holds the Team cursor: `ptb.team-update` entries
  and `team_sync` results. Compaction, fork and tree navigation keep it.
- Each Session has one publisher, and it publishes only while the lead is idle.
  A competing `team_sync` returns `observation_in_progress`.
- The provider ACK path, supersession and hidden observations are removed.
  Decision 0020 supersedes decision 0016.

## Worker liveness from the process generation

- PTB identifies a Worker process by its generation: PID, birth token and boot
  ID. Linux reads procfs. macOS uses a small Rust helper.
- Elapsed time never closes a pane. An aborted or failed turn no longer marks a
  Worker failed.
- A durable launch ID fences each launch. A launch or recovery that does not
  start becomes `launch_stalled` with `ask_human`. PTB never spawns again on an
  unknown result.
- Attention results state the cause and the next action: `session_switched`,
  `launch_stalled`, `legacy_unverified`, `generation_helper_missing` and
  `receipt_deadline`.
- `/ptb status` shows the cause of an unknown state. It can adopt a bound Worker
  that has no birth token.
- Decision 0021 amends decision 0018.

## macOS helper

`postinstall` builds the helper when `rustc` is available. Without `rustc`,
installation succeeds and PTB warns once at Pi startup with the remedy. Plain
`/reload` in the same Pi process stays admitted. A replacement with a different
PID waits until the helper is available.

## Verification

- Deterministic simulator: fast-check campaigns, history monitors, mutant gate
  M1-M6 and replay of anonymized real traces.
- Real Herdr and Pi runs of liveness items 1, 3, 5 and 9 on macOS.
- Not verified: Linux probes A7 and A9; scale of 20 leads with 50 Workers each.
