# Pi Team Bright v0.21.1

## Adaptive Worker panes

Herdr now splits the most suitable current Worker pane instead of following a
fixed grid. The leader keeps its configured space. Placement follows live pane
sizes and refuses splits below 20 columns by 5 rows.

Use this Team policy in `team_create` or `pi_team_bright.team.pane_layout`:

```json
{
  "leader_share": 0.6,
  "worker_tiling": "adaptive",
  "columns_per_row": 2,
  "worker_limit": 8
}
```

`columns_per_row` controls the visual split bias. Use `2` to favor side-by-side
panes or `3` to favor stacked panes. `worker_limit` caps current active Workers;
stopping a Worker frees a slot. Omit the limit to retain unlimited admission.
Geometry can still prevent another pane before the limit is reached.

Existing `grid` settings select adaptive placement. `linear` remains the default
and keeps its existing behavior. The command palette exposes the new settings.
Settings changes apply to new Teams.

## Leader pane names

Team creation names the exact Herdr leader pane `<team name>-leader`. A naming
failure warns without failing Team creation. Worker pane naming is unchanged.

## Session discovery repair

An unrelated Team with settings unknown to the running version could block every
strict Session lookup. Discovery now reads Membership identity before validating
matching Team settings. Invalid matching records and unreadable identity still
refuse. Team creation also refuses ambiguous or stale bindings and reports the
underlying reason.

## Delegation guidance

The lead retains judgment and the final assessment. Workers implement bounded
changes and establish facts. A second opinion remains opt-in at the user's
request. These guidance changes add no runtime role or tool.

## Upgrade

Install `pi install npm:@hypercarrier/pi-team-bright@0.21.1`, then restart Pi.
No Team storage migration is required. Finish active Teams on their current
runtime before upgrading. Restarting also loads the Session-discovery repair;
an already-running older process retains its old validation behavior.

Pi `>=0.83.0` remains required. This release adds optional pane-policy fields and
an `adaptive` value. Older versions may reject Teams that use those fields.
The public Membership observation protocol and Worker Task tools are unchanged.
